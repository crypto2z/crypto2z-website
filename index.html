Lightning Node — steve2z
Running a public Lightning node on a Raspberry Pi 5 with NVMe storage and a full Bitcoin Core backend via MyNode. Online since 2021/2022, claimed on Amboss, connected via Zeus on iOS.

DCA Bot
A Python bot running on DigitalOcean that executes automated dollar-cost averaging trades on Coinbase Advanced Trade — Mon/Wed/Fri, $2/coin, 8 assets. Includes volatility-based dip buying and a trailing stop system.
